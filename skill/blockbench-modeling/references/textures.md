# Texture creation and mapping (plugin 1.1+)

Texture methods run as individual undo steps, not operations inside modeling `batch` (except `texture.assign` and `face.update`). Prefer JSON files for parameters. All color strings are `#RRGGBB` or `#RRGGBBAA`.

## Procedural texture generation

`texture.generate`:

```json
{"name":"wood.png","width":64,"height":64,"pattern":"wood","colors":["#d1a16c","#835430"],"cell":8,"seed":42}
```

Patterns: `solid`, `checker`, `noise`, `wood`, `brick`, `metal`, `gradient`. Width/height are 1–2048. `colors` has 1–32 entries; `cell` is 1–1024; seed is an unsigned 32-bit integer. Gradient is vertical unless `direction:"horizontal"`. These are deterministic code-generated patterns, not neural image generation. Returns a texture UUID. Export with `texture-export UUID file.png`.

`texture.paint` accepts `{id,commands:[...]}`. The complete command list validates on a temporary canvas before committing bitmap changes. Supported commands:

```json
{"id":"texture UUID","commands":[
  {"shape":"rect","rect":[0,0,16,16],"color":"#334455"},
  {"shape":"pixel","point":[2,3],"color":"#ffffff"},
  {"shape":"line","from":[0,0],"to":[15,15],"width":1,"color":"#ffa500"},
  {"shape":"ellipse","rect":[4,4,8,8],"color":"#00aaff"},
  {"shape":"polygon","points":[[0,0],[8,0],[4,8]],"color":"#ff0000"},
  {"shape":"clear","rect":[0,0,2,2]}
]}
```

`rect` is `[x,y,width,height]`, in image pixels. Commands are clipped by the image bounds. Up to 10000 commands per call. Curves/lines may be anti-aliased by Canvas; use integer rectangles/pixels for crisp pixel art. Layered textures must be flattened first. Undo restores the bitmap.

## Assign and map an image

1. Import external PNG with CLI `texture image.png`, or use `texture.generate`.
2. Call `texture.map` with `{texture:"UUID",ids:["element UUID"],rect?:[u1,v1,u2,v2]}`.
3. Inspect screenshot and texture image.

`texture.map` sets texture and UVs together. Cubes and billboards map every face to the whole texture/rectangle. Mesh faces project along their dominant normal and scale into that rectangle. Splines use their native generated UVs. The rectangle uses logical UV pixels (`texture.getUVWidth()/Height()`), which may differ from PNG pixels in formats using a global texture resolution. The default rectangle uses the correct logical dimensions. Mapping an entire texture per face is suitable for repeating material tiles but causes overlap; use an atlas for independent per-face painting.

`texture.assign` only changes the assigned image and preserves existing UVs. `face.update` edits one specific face's UVs. Billboard face key is `front` and its UV representation is the same 4-number rectangle as a cube.

## Automatic atlas

```json
{
  "ids":["body","head","mesh UUID"],
  "name":"model_atlas.png",
  "width":256,"height":256,"tile":24,"padding":2,
  "material":{"pattern":"metal","colors":["#8197a8","#c1d5e2"],"cell":8},
  "materials":{"head":{"pattern":"checker","colors":["#40a7b8","#81d4d7"],"cell":4}}
}
```

Call `texture.atlas`. Every cube/mesh/billboard polygon receives a separate equal square tile; image creation, assignments and UV changes are one undo step. `materials` is keyed by element UUID or name; UUID has priority. Return includes texture UUID and a `mapping` array with element UUID, face key, image-pixel `rect`, and logical `uv` values. Spline UVs are generated by Blockbench and are not packed by this method. Width/height: 16–4096, tile: 2–512, padding: 0–16. Insufficient space is rejected before changing the scene.

This is face-by-face planar mapping, not seam-aware organic unwrapping. Equal square tiles can stretch long faces and use space inefficiently. Use the returned map to refine individual UVs, or manually plan a precise atlas for production assets. Material patterns may show seams; inspect all important views.

## AI-painted images / atlas replacement

When an image generation tool is available, use it for semantic or reference-based texture design. Keep the result as a PNG in the task workspace. This plugin itself does not call an external AI service or require a key.

For new seamless material tiles, generate/import the PNG, then `texture.map`.
For an atlas, first create/export it and keep its layout. Supply the image and mapping as the editing reference, requiring identical dimensions/tile boundaries and no geometry changes. Inspect the result before replacing:

```powershell
python <skill>/scripts/blockbench.py texture-export TEXTURE_UUID atlas.png
python <skill>/scripts/blockbench.py texture painted-atlas.png --replace TEXTURE_UUID
```

`texture.replace` checks dimensions match and preserves texture UUID, existing logical UV size, and all assignments; bitmap undo is supported. It intentionally does not rescale a generated image or reinterpret its UV layout. The PNG import limits are 8 MB through CLI and 8192 pixels per side. If image generation is unavailable, do not present procedural output as an AI-painted result.
